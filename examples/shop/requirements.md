# Checkout acceptance criteria (sample evidence)

- A £100 order with SAVE10 displays a total of £90.00.
- An invalid code displays "Discount code is not valid" in an alert.
- An invalid code leaves the order total at £100.00.
- The field is labelled "Discount code"; the button is "Apply discount".
- The total uses the test ID "order-total".

These files are a repository fixture, not a running shop. They demonstrate how
Buggle can ground a proposed scenario in supplied acceptance criteria.
